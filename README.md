# 有春 Uchun・公開網頁（隱私政策）

這個資料夾是發布到 GitHub Pages 的靜態頁，網址 `https://coulson-kt.github.io/uchun-auth/`（公開 repo `coulson-KT/uchun-auth`，2026-10-31 建）。

- `privacy/index.html`：隱私政策。App 設定頁「隱私政策」按鈕、App Store Connect 的隱私政策網址都指到 `https://coulson-kt.github.io/uchun-auth/privacy/`。
- `oauth/consent/` 已於 2026-10-31 隨 MCP 一起移除（Coulson 決定「日後想清楚再加回來」）；要加回來從 git 歷史取（提交 `7e8a853` 的 `web/oauth/consent/index.html`）。

發布方式：把這個資料夾的內容（含 `.nojekyll`）推到 `uchun-auth` repo 的 `main`，GitHub Pages 從 `main` 根目錄發布。改內容只改這裡再推，不在 GitHub 網頁上直接改。
